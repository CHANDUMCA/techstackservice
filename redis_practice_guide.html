Spring Boot + Redis + Kubernetes + Log4j2
Master Reference Guide

💡 About this Document: This is a complete, step-by-step master reference guide. It contains all code snippets, directory mappings, configuration files, and terminal commands needed to build, configure, dockerize, and deploy a logging-enabled Spring Boot Redis app to Kubernetes.

🗺️ Complete Roadmap Overview

🚀 Phase 1: Local Spring Boot & Redis Setup
  1. Create the Spring Boot maven project with Web, H2, and JPA dependencies.
  2. Add the Redis Starter dependency in pom.xml.
  3. Configure Redis connection details in application.properties.
  4. Create the Java package com.sunrize.it.redis.
  5. Implement the Java configuration class RedisConfig.java.
  6. Implement the utility service class RedisService.java.
  7. Create the REST controller RedisController.java to test set/get APIs.
🪵 Phase 2: Log4j2 Logging & Local Externalization
  1. Exclude default logging (Logback) from the starters in pom.xml and add Log4j2.
  2. Create log4j2-spring.xml to write logs to a dynamic directory (LOG_PATH).
  3. Configure annotation processing in STS for Lombok and add @Slf4j to RedisController.java.
  4. Verify local log output in D:\GIT\logs by running the app with -DLOG_PATH.
☸️ Phase 3: Dockerization & Kubernetes Deployment
  1. Create a Dockerfile that passes -DLOG_PATH=/app/logs.
  2. Build the Docker image locally and load it into Minikube's cache.
  3. Configure Kubernetes manifests for Redis (redis-k8s.yaml).
  4. Configure Kubernetes manifests for the application (app-k8s.yaml) with volume mounts.
  5. Mount the Windows directory to Minikube, deploy the cluster, and test APIs.

📋 Prerequisites

  • Java JDK 21 installed and environment variables configured.
  • Maven 3.x (or Maven Wrapper mvnw included in project).
  • Docker Desktop for Windows (configured to use Windows containers or Linux containers).
  • Minikube and kubectl command line tools.
  • Spring Tool Suite (STS) or Eclipse IDE.

2. Java Configuration Class

RedisConfig.java

Uses StringRedisSerializer for keys and GenericJacksonJsonRedisSerializer for serializing values as readable JSON text in Redis.

package com.sunrize.it.redis;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.redis.connection.RedisConnectionFactory;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.data.redis.serializer.GenericJacksonJsonRedisSerializer;
import org.springframework.data.redis.serializer.StringRedisSerializer;

@Configuration
public class RedisConfig {

    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory connectionFactory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(connectionFactory);
        
        // Serialize keys as Strings
        template.setKeySerializer(new StringRedisSerializer());
        template.setHashKeySerializer(new StringRedisSerializer());
        
        // Serialize values as JSON
        GenericJacksonJsonRedisSerializer serializer = GenericJacksonJsonRedisSerializer.builder().build();
        template.setValueSerializer(serializer);
        template.setHashValueSerializer(serializer);
        
        template.afterPropertiesSet();
        return template;
    }
}

3. Redis Helper Service

RedisService.java

Provides abstraction over RedisTemplate operations.

package com.sunrize.it.redis;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.stereotype.Service;
import java.util.concurrent.TimeUnit;

@Service
public class RedisService {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    public void set(String key, Object value) {
        redisTemplate.opsForValue().set(key, value);
    }

    public void set(String key, Object value, long timeoutInSeconds) {
        redisTemplate.opsForValue().set(key, value, timeoutInSeconds, TimeUnit.SECONDS);
    }

    public Object get(String key) {
        return redisTemplate.opsForValue().get(key);
    }

    public boolean delete(String key) {
        return Boolean.TRUE.equals(redisTemplate.delete(key));
    }

    public boolean hasKey(String key) {
        return Boolean.TRUE.equals(redisTemplate.hasKey(key));
    }
}

4. Logging-Enabled REST Controller

RedisController.java

Provides API endpoints to GET, SET, and DELETE keys from Redis, complete with SLF4J logging.

package com.sunrize.it.redis;

import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

@Slf4j
@RestController
@RequestMapping("/api/redis")
public class RedisController {

    @Autowired
    private RedisService redisService;

    @PostMapping("/set")
    public String setKey(
            @RequestParam String key,
            @RequestParam String value,
            @RequestParam(required = false) Long ttl) {
        
        log.info("Received POST request to set key: '{}' with value: '{}', TTL: {}", key, value, ttl);
        
        if (ttl != null) {
            redisService.set(key, value, ttl);
            log.debug("Successfully saved key: '{}' with TTL: {}s", key, ttl);
            return "Key '" + key + "' set with value '" + value + "' and TTL " + ttl + " seconds successfully!";
        } else {
            redisService.set(key, value);
            log.debug("Successfully saved key: '{}' without TTL", key);
            return "Key '" + key + "' set with value '" + value + "' successfully!";
        }
    }

    @GetMapping("/get/{key}")
    public Object getKey(@PathVariable String key) {
        log.info("Received GET request to retrieve key: '{}'", key);
        
        Object value = redisService.get(key);
        if (value == null) {
            log.warn("Key '{}' was not found in Redis.", key);
            return "Key '" + key + "' not found in Redis.";
        }
        
        log.debug("Retrieved value for key '{}': '{}'", key, value);
        return value;
    }

    @DeleteMapping("/delete/{key}")
    public String deleteKey(@PathVariable String key) {
        log.info("Received DELETE request for key: '{}'", key);
        
        boolean deleted = redisService.delete(key);
        if (deleted) {
            log.debug("Successfully deleted key: '{}'", key);
            return "Key '" + key + "' deleted successfully.";
        } else {
            log.warn("Failed to delete key '{}'. Key might not exist.", key);
            return "Key '" + key + "' not found or could not be deleted.";
        }
    }
}

🛠️ Phase 3: Log4j2 Configuration

1. Log4j2 XML Layout Configuration

src/main/resources/log4j2-spring.xml 
<?xml version="1.0" encoding="UTF-8"?>
<Configuration status="WARN">
    <Properties>
        <Property name="LOG_DIR">${sys:LOG_PATH:-./logs}</Property>
        <Property name="LOG_FILE_NAME">techstackservice</Property>
    </Properties>
    
    <Appenders>
        <Console name="Console" target="SYSTEM_OUT">
            <PatternLayout pattern="%d{yyyy-MM-dd HH:mm:ss.SSS} [%t] %-5level %logger{36} - %msg%n"/>
        </Console>
        
        <RollingFile name="RollingFile" 
                     fileName="${LOG_DIR}/${LOG_FILE_NAME}.log" 
                     filePattern="${LOG_DIR}/${LOG_FILE_NAME}-%d{yyyy-MM-dd}-%i.log.gz">
            <PatternLayout pattern="%d{yyyy-MM-dd HH:mm:ss.SSS} [%t] %-5level %logger{36} - %msg%n"/>
            <Policies>
                <TimeBasedTriggeringPolicy interval="1" modulate="true"/>
                <SizeBasedTriggeringPolicy size="10 MB"/>
            </Policies>
            <DefaultRolloverStrategy max="10"/>
        </RollingFile>
    </Appenders>
    
    <Loggers>
        <Root level="INFO">
            <AppenderRef ref="Console"/>
            <AppenderRef ref="RollingFile"/>
        </Root>
        
        <Logger name="com.sunrize.it" level="DEBUG" additivity="false">
            <AppenderRef ref="Console"/>
            <AppenderRef ref="RollingFile"/>
        </Logger>
    </Loggers>
</Configuration>

🐳 Phase 4: Dockerization

1. Dockerfile

Dockerfile

Leverages JRE 21 and overrides Log4j2's default path to point to /app/logs internally.

# Use JRE 21 alpine image
FROM eclipse-temurin:21-jre-alpine

# Set directory inside the container
WORKDIR /app

# Copy the built maven WAR file
COPY target/techstackservice-0.0.1.war app.war

# Expose HTTP port
EXPOSE 8080

# Run Spring Boot and configure the log directory inside the container
ENTRYPOINT ["java", "-DLOG_PATH=/app/logs", "-jar", "app.war"]

# Package war file
mvnw clean package -DskipTests

# Build Docker image

🏃‍♀️ Phase 6: Startup & Deployment Workflow (From Stopped State)

Follow these steps exactly to start the infrastructure, clear stale caches, mount host directories, and route endpoints.

Step 1: Start Infrastructure

# 1. Start Docker Desktop from Windows Start Menu
# 2. Wait for green "Engine Running" status
# 3. Start the Minikube cluster
minikube start

Step 2: Clear Minikube Cached Image & Load Fresh Image

💡 Note: If you rebuild your image locally on Windows, Minikube will still run its cached version unless you force delete it. 
# 1. Delete the app resources so the image is not in use
kubectl delete -f k8s/app-k8s.yaml

# 2. Delete the old image from Minikube cache
minikube image rm techstackservice:1.0

# 3. Load the newly built image
minikube image load techstackservice:1.0

# 4. Redeploy the app manifest
kubectl apply -f k8s/app-k8s.yaml

Step 3: Setup Directory Mounting

Link the Windows folder D:\GIT\logs to the Minikube directory /data/logs. Open a **new terminal** and run:

minikube mount "D:\GIT\logs:/data/logs"
⚠️ Crucial Ordering Rule: If the pod started *before* running the mount tunnel, it will write to Minikube's local disk. You must run kubectl rollout restart deployment/techstackservice-deployment to trigger a restart while the mount is running.

Step 4: Expose Service Tunnel

Open **another separate terminal** and run:

minikube service techstackservice-service

Take note of the active tunnel port (e.g. 61225).
